# Folder Template Kop Surat Travel (Letterhead)

Folder ini khusus digunakan untuk menyimpan file gambar/template **Kop Surat Resmi Travel**.

## Cara Penggunaan:
1. Simpan file gambar Kop Surat Anda ke dalam folder ini:
   `public/templates/kop-surat/`

2. Format nama file yang disarankan:
   - `kop-surat.png` (Rekomendasi format PNG latar transparan atau putih)
   - `kop-surat.jpg`
   - `kop-surat.jpeg`

3. Gambar Kop Surat ini akan otomatis digunakan oleh sistem sebagai header lembar **Formulir & Surat Pernyataan Pendaftaran Jamaah Umroh**.
