# Folder Template Surat

Folder ini disediakan khusus untuk menyimpan file **Template Surat** (`.docx` / `.doc` / `.png`) dan berkas **Kop Surat**.

---

## 📋 Panduan Penggunaan:
1. Tempatkan file template surat atau kop surat Anda di dalam folder ini:
   `public/templates/surat/`
2. Ekstensi file yang didukung: `.docx`, `.doc`, `.png`, `.jpg`, `.jpeg`.
3. Setelah file dimasukkan, sistem akan langsung mengenali dan menggunakannya untuk pencetakan dokumen pendaftaran.
