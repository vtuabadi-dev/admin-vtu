# Folder Template Surat & Kop Surat

Folder ini digunakan untuk menempatkan file **Template Surat**, **Kop Surat**, dan **Formulir Pendaftaran** resmi Travel VTU.

---

## 📁 Struktur Lokasi & Penggunaan File

| Nama File / Subfolder | Format yang Diizinkan | Fungsi / Tujuan |
|---|---|---|
| `template-surat.docx` / `template-surat.png` | `.png`, `.jpg`, `.docx` | Template utama lembar formulir & surat pendaftaran |
| `kop-surat.png` | `.png`, `.jpg`, `.jpeg` | Gambar Kop Surat Header resmi VTU Travel |

---

## 💡 Cara Menaruh File Kop Surat / Template Surat:
1. Simpan gambar kop surat Anda dengan nama file **`kop-surat.png`** atau **`template-surat.png`**.
2. Masukkan file tersebut ke dalam folder ini (`public/templates/template-surat/` atau `public/templates/kop-surat/`).
3. Sistem secara otomatis akan membaca dan menampilkan Kop Surat tersebut di bagian atas formulir pendaftaran digital & cetak PDF.
